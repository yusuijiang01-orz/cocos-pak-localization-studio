## 完整 XLSX v7 结构闸门

- XLSX `text` 列不得出现运行时占位符、标签、路径、受保护数字或 `◈` 运输标记。
- 导出前增量重扫每个 PAK，补入此前因 INI 键名未知而漏掉、但值本身是自然语言的玩家界面文字；资源引用和内部结构键仍排除。
- 导入必须从本地 mapping 骨架恢复全部结构片段；缺失自然语言译文回退原文，但不阻止构建。
- 导入完成必须报告仍含越南语变音字符的玩家可见记录数；文件写入成功不等于完全汉化。
- 导入结果同时报告残留去重片段数和资源引用处数，并自动生成只含残留去重片段的第二轮 XLSX；未出现在稀疏表中的既有中文必须原样保留。
- 多 PAK 导入后逐 PAK 物化资源；多 PAK 构建逐个报告输出与失败目标。
